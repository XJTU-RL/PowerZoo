## 0. 论文核验结论（2026-11-20，v2 重标定的依据）

对原文 Fig.5 做高清像素读数（300dpi 渲染，以 CBESS cap.=1000 kWh
已知柱锚定刻度，锚柱读数误差 ~1%），并用 Table VI 做独立定量交叉：

1. **Fig.5(a) 与 Fig.5(b) 互相自洽**——PV 峰 ~195 kW 的钟形积分 ≈1390
   kWh/日 = (b) 的 PV 柱（全图最高柱，≈1.35×CBESS）；负荷柱
   1030+480=1510 kWh/日 ↔ (a) 的双峰/午间深谷形态。
   v1 曾声称「两图自相矛盾（850/24h 出不了 200 kW 峰）」系误诊：
   把 base-only 柱的均值与 base+EV 合成峰错位对比。**此项已更正。**
2. **论文真正的内部矛盾在 Fig.5 ↔ Table VI**：式(37b) 的弃光率分母为
   全部可用 PV 能量，Table VI 给 PISTG-LDCPPO 68.2 kWh/日 @ 1.71%
   → 反推总可用 PV ≈ 4.0 MWh/日（69-bus 反推 161 kWh/母线/日，交叉
   一致）；而 Fig.5(b) 隐含 26×1390 ≈ 36 MWh/日——**差 ~9 倍**，
   任何聚合口径读法都无法调和。
3. **弃光率 1.71% 在论文字面场景下物理不可达**：Fig.5 口径的午间
   盈余 ~2.7-4.6 MW ≫ 4×250 kW=1 MW 的 CBESS 充电能力与 3.2 MWh
   库容，弃光两位数百分比是物理下限（实测口径见 D-2）。
4. 表 I「PV 装机峰 = 0.9×母线峰荷」规则与上述两条现象线索（PV 柱、
   Fig.9(a) 过压幅度）不一致：字面 0.9 定容实测 Vmax 仅 1.01-1.03，
   约为论文基线画幅（~1.05+）的一半。

## D. 已知与论文的差异（如实报告，不掩盖）

1. **夜间欠压更深**：v2 零控制 Vmin 0.876-0.889 vs 论文 Fig.9(a) 的
   0.90-0.95（EV 柱字面 480 kWh 夜间负荷较重所致）；CBESS 夜间放电
   （±250 kW×4）有充分调节空间，方向与论文一致。未为凑夜压区间
   而再调参——如需，微调 NON_DER_SCALE 即可，但不做无依据标定。
2. **弃光率与 Table VI 的矛盾不可调和**：v2 字面口径可用 PV 27.1
   MWh/日（Fig.5(b) 柱口径），午间反送 2.7-4.6 MW ≫ CBESS 1 MW/
   3.2 MWh，弃光两位数百分比是物理下限；论文 1.71%（反推 4.0
   MWh/日）无法用论文自述场景达成。弃光率数值本身待 v2 全量训练实测。
3. **STG 与 PISTG 的物理残差差**（表 VII 口径）在小规模预训练下未拉开
   （KCL 残差 1.50e-2 vs 1.47e-2）——recon 损失也间接压低物理一致性；
   论文 2000 回合规模下可能拉开，以 v2 全量运行结果为准。
4. **训练规模**：本机单 seed 全量（2000 回合×3 方法）；论文 8×3090、
   5 runs×8 方法。多 seed/其余基线为第二阶段。
5. **电价为合成剖面**：论文的真实电价数据源未公开，形态与水平按 NEM
   常识标定。
6. **v1 全量结果已过时**：`results/pistg_ldcpo/full_*` 为 v1 标定
   （基荷 1600/EV 300/PV_BOOST 1.5/价格 0.55）下产出，留作对照，
   勿与 v2 结果混读；结果报告中的对应结论按 v1 口径理解。
