# 交互展示的数据来源与复现

本页数据来自 PowerZoo 仓库中 IEEE13 节点派生模型的 **54次 OpenDSS 原生稳态求解**。网页选择已求解的工况，显示节点电压、网损和主网输入；浏览器不实时求解，不使用强化学习策略，也不展示训练收敛结果。

## 模型与工况

- 模型：`node_systems/13Bus/network.dss`，包含16个实际计算母线（含源端和调压器辅助母线）及17条线路或变压器连接。
- 负荷倍率：0.6至1.4，步长0.1，共9档。
- 调压器：所有原生RegControl采用相同档位，−4、0、+4档，每档变比0.00625。
- 电容器：全部退出或全部投入，共2种状态。
- 储能有功设为0 kW；沿用模型其余原生配置，该模型没有PVSystem。
- 各工况重新编译模型，关闭自动调压控制，独立求解；不推进时间，不将54个快照解释为连续运行轨迹。
- 仅统计真实1、2、3相节点，缺相保留缺相，中性点不纳入电压统计。

0.95–1.05 p.u. 是展示参考带，部分手动控制工况存在明显低电压，按实际结果显示。该扫掠不是优化策略或安全运行建议。

## 可追溯记录

源代码基线：`70401e88f9055f820b5a17d4f532262b4b5d5295`。

JSON的 `provenance` 保留了模型文件及整体SHA-256、导出脚本SHA-256、复现命令、Python和DSS引擎版本、设备名称以及控制条件。每个快照保存有功功率平衡残差。

本次生成环境为Python 3.11.15、DSS-Python 0.15.7、DSS-Python Backend 0.14.5。54次求解均收敛；最大有功平衡残差约0.00003669 kW，低于导出器0.05 kW校验门槛。不同控制组合的所有实际相电压范围为0.81717–1.03382 p.u.，不代表全部工况电压合格。

数据文件SHA-256：`5c2222d7635d2efbe1656c959327fbf9060ce7222beab3368cbdb338d08fc82b`。本环境重复导出得到逐字节一致文件；跨平台或引擎版本更换可能产生浮点差异。

## 复现

在仓库根目录、已安装项目依赖的Python环境中运行：

```sh
python scripts/export_showcase.py --output docs/showcase/data/vvc-13bus.json --source-commit 70401e88f9055f820b5a17d4f532262b4b5d5295
```

仅复现这个导出器可使用隔离环境安装 `dss-python==0.15.7`、`dss-python-backend==0.14.5`、`numpy==1.26.4`、`networkx==3.4.2`。上述源基线指本次所使用的模型与物理会话代码；修改这些输入后应更新来源版本并重新生成数据与摘要。

导出器通过DSSSession复制模型到临时目录，求解不修改原始DSS模型；任何不收敛、非有限电压或超限功率平衡残差都会使导出失败。
