# 优化 123 节点 LFC：固定下垂对照预注册（草案）

与已验收的单向脉冲传递分开。本方案不是论文复现，也不改变已有
123 探针、SLX 或默认训练配置。三条轨迹从同一确定性始点启动：

- 独立无扰动、无附加控制：仅用于检验自然漂移。
- 同一扰动、无附加控制：四台储能始终为零。
- 同一扰动、固定下垂：使用无附加控制组静置尾段的固定频率参考。

20 s 预热，20–25 s 静置，25–35 s 两个扰动组均额外施加
+100 kW，35–45 s 释放。+100 kW 作为独立外生项加入动态负荷
有功命令并单列，不计为馈线输出；不加无功，不碰固定负荷。馈线
保持 unity gain。静置尾段取扰动前 3 s，各组先检查始点和漂移。
1 s 通信步，输入为严格早于实际暂停时刻的最近原生频率样本；
不能用等时刻歧义点。公共基准、固定增益 200,000 kW/Hz、死区
0.1 mHz、每台限 ±50 kW，全程不调参。每台还检查端口 P/Q、
SOC 连续性和基于 1 s、200 kWh、95% 双侧效率的实测能量账。

## 在线观测和待运行的对照

先独立验证了在线读数：在 MATLAB R2025b 中，仅在临时复制的模型
内将唯一的 `IEEE9BusSystem/To Workspace1`（SID 3596）日志由
Array 改为 Timeseries，不保存模型。其余记录参数和
`ReturnWorkspaceOutputs=off` 不变。在实际暂停 20.033333 s、
21.033333 s 时读取原生频率样本 (20.0 s, 59.9680498174 Hz) 和
(21.0 s, 59.9680498064 Hz)。两次暂停所见的整个时间戳/频率序列
均与同一运行停机后记录的前缀精确一致。不借用 `out_t`，不改变
采样相位和步长；本次观测没有扰动或控制。

新增对照入口每组启动全新引擎。固定版本模型仅在临时目录载入，
仍逐次校验在线原生时间戳并与同信号停机记录核对。读取失败、样本
陈旧或超前、物理传感器缺失时均不能通过。已取得的分组进度、
命令/端口记录和逐帧实测摘要以独占创建的私有 JSONL 留存。
