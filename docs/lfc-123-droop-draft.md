# 优化 123 节点 LFC：固定下垂对照

与已验收的单向脉冲传递分开。本方案不是论文复现，也不改变已有
123 探针、SLX 或默认训练配置。三条轨迹从同一确定性始点启动：

- 独立无扰动、无附加控制：仅用于检验自然漂移。
- 同一扰动、无附加控制：四台储能始终为零。
- 同一扰动、固定下垂：使用无附加控制组静置尾段的固定频率参考。

20 s 预热，20–25 s 静置，25–35 s 两个扰动组均额外施加
+100 kW，35–45 s 释放。+100 kW 作为独立外生项加入动态负荷
有功命令并单列，不计为馈线输出；不加无功，不碰固定负荷。馈线
保持 unity gain。静置尾段取扰动前 3 s，各组先检查始点和漂移。
1 s 通信步，输入为严格早于实际暂停时刻的最近原生频率样本；
不能用等时刻歧义点。公共基准、固定增益 200,000 kW/Hz、死区
0.1 mHz、每台限 ±50 kW，全程不调参。每台还检查端口 P/Q、
SOC 连续性和基于 1 s、200 kWh、95% 双侧效率的实测能量账。

## 在线观测和对照运行方法

先独立验证了在线读数：在 MATLAB R2025b 中，仅在临时复制的模型
内将唯一的 `IEEE9BusSystem/To Workspace1`（SID 3596）日志由
Array 改为 Timeseries，不保存模型。其余记录参数和
`ReturnWorkspaceOutputs=off` 不变。在实际暂停 20.033333 s、
21.033333 s 时读取原生频率样本 (20.0 s, 59.9680498174 Hz) 和
(21.0 s, 59.9680498064 Hz)。两次暂停所见的整个时间戳/频率序列
均与同一运行停机后记录的前缀精确一致。不借用 `out_t`，不改变
采样相位和步长；本次观测没有扰动或控制。

新增对照入口每组启动全新引擎。固定版本模型仅在临时目录载入，
仍逐次校验在线原生时间戳并与同信号停机记录核对。读取失败、样本
陈旧或超前、物理传感器缺失时均不能通过。已取得的分组进度、
命令/端口记录和逐帧实测摘要以独占创建的私有 JSONL 留存。
经独立审查后，使用已有匹配的 MATLAB/Python Engine 和 Xvfb：

```sh
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  timeout --kill-after=15s 900s xvfb-run -a python -m scripts.check_lfc_123_droop \
  --report /path/to/new/private-123-droop.jsonl
```

在线遥测验证不能替代以下对照和物理验收。

两扰动组至少连续两个事件帧，其端口动作、实测 PCC 及实测
Bus 8 功率都须符号一致；PCC、Bus 8 的有效差均至少 25 kW，
两者差值不超过 25 kW。小于检测门槛且所有完整性门槛通过为
“未见可辨响应”，资源命令可辨但物理证据不充分、原生采样或
配对失败则为“不确定”。冻结阈值配置见 `droop_v1.json`。
频率最低值、离差面积、释放末值与饱和次数只供诊断，单组配对
不证明调频收益；控制器读取频率并不等于馈线可双向接收输电状态。
MPC、训练和论文结果均不在本阶段。

`python -m unittest tests.test_lfc_123_droop_draft` 仅运行合成数据测试。

## 单次对照结果：不确定

按原先冻结参数，用 MATLAB R2025b 和 DSS-Python 0.15.7 运行提交
`867359cb`。三组均完成 25 个通信帧，实际终点均为 45.033333 s。
两扰动组都在 25–35 s 加入 +100 kW；扰动前 Bus 8 的有功和无功
在三组一致。75 次暂停的在线频率均与停机后同一原生记录一致。
Bus 8 绝对跟踪误差最大为 24.444 kW / 14.966 kvar；馈线有功
平衡残差最大为约 0.0000063 kW，单台储能单帧能量账残差小于
0.000000000001 kWh。四台储能均未饱和，单台最大指令 26.112 kW。

固定下垂在 26、28、30、32、34 s 五个通信帧分别产生可辨的正向
储能注入，合计 97.970–104.448 kW；相对同扰动无附加控制组，
馈线入口有功下降 101.565–108.252 kW，Bus 8 实测有功下降
102.034–108.769 kW，两个位置的最大配对差为 0.517 kW。
五个响应帧被零指令帧隔开，不满足预先约定的“至少两个连续帧”。
因此脚本按设计退出码 1（`inconclusive`），不是仿真中断，
也不是完全无响应。此前单向脉冲传递的独立验收不受影响。

频率只作诊断：两扰动组的最低值分别为 59.9674103 Hz 和
59.9674276 Hz，相差约 0.0173 mHz；采样绝对偏差面积分别约
0.00549 和 0.00294 Hz·s。一次配对不能证明调频收益或策略优越。
原始 JSONL 不随仓库发布。

## 下一版设计边界

保留本版增益、门槛和结果，不用本次测试扰动回调参数。另设一个
独立的标定扰动，先辨识 1 s 通信和测量延迟下从储能/PCC 到 Bus 8
频率的采样响应，再据此设计确定性的阻尼和每步变化率限制。冻结
控制律、参数与验收门槛后，才用未参与标定的验证扰动和匹配无控制组
比较。此处不更改控制器，也不增加仿真结果。
