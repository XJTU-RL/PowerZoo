# 优化 123 节点 LFC：固定下垂对照预注册（草案）

与已验收的单向脉冲传递分开。本方案不是论文复现，也不改变已有
123 探针、SLX 或默认训练配置。三条轨迹从同一确定性始点启动：

- 独立无扰动、无附加控制：仅用于检验自然漂移。
- 同一扰动、无附加控制：四台储能始终为零。
- 同一扰动、固定下垂：使用无附加控制组静置尾段的固定频率参考。

20 s 预热，20–25 s 静置，25–35 s 两个扰动组均额外施加
+100 kW，35–45 s 释放。+100 kW 作为独立外生项加入动态负荷
有功命令并单列，不计为馈线输出；不加无功，不碰固定负荷。馈线
保持 unity gain。静置尾段取扰动前 3 s，各组先检查始点和漂移。
1 s 通信步，输入为严格早于实际暂停时刻的最近原生频率样本；
不能用等时刻歧义点。公共基准、固定增益 200,000 kW/Hz、死区
0.1 mHz、每台限 ±50 kW，全程不调参。每台还检查端口 P/Q、
SOC 连续性和基于 1 s、200 kWh、95% 双侧效率的实测能量账。

## 运行阻塞及验收

现有证明只覆盖 Simulink 停止后的 `out_f_load1` / `out_t`，
并未证明暂停期间可以读到同一 Bus 8 信号的原生时间戳和频率值。
草案只实现数据契约、控制律和配对验收，不提供 MATLAB 适配器或
可启动的 CLI。下阶段先独立核查暂停可见性；真值输入须携带信号
自身时间戳，验证有新点、无越界未来点，并与独立停机日志逐样比对。
不得用另一个输出的时间戳、从 0.2 s 间隔反推时刻、插值或回放
预知数据替代。必要时另审显式的时间戳配对观测通道。

两扰动组至少连续两个事件帧，其端口动作、实测 PCC 及实测
Bus 8 功率都须符号一致；PCC、Bus 8 的有效差均至少 25 kW，
两者差值不超过 25 kW。小于检测门槛且所有完整性门槛通过为
“未见可辨响应”，资源命令可辨但物理证据不充分、原生采样或
配对失败则为“不确定”。冻结阈值配置见 `droop_v1.json`。
频率最低值、离差面积、释放末值与饱和次数只供诊断，单组配对
不证明调频收益；控制器读取频率并不等于馈线可双向接收输电状态。
MPC、训练和论文结果均不在本阶段。

`python -m unittest tests.test_lfc_123_droop_draft` 仅运行合成数据测试。
