# 独立工况的配网可交付能力估计

本轮沿用 7173bd97 的双 IEEE34 接力系统、两个馈线固定电压源及原生三机九节点动态模型。每个完整工况使用独立初态和独立 MATLAB 进程产生一个原始轨迹，两端及其所有衍生样本绑定在该工况的一个划分。主网外生阶跃为 +28 kW，保留原有基线锚点，回传两端相对于各自新工况初始进口的实际增量。此试验估计馈线本地可交付能力。

预先冻结源码 `0163ee2ff5c3765b1fad8ed5cb17479153b3f231`。组名的三个字母顺序为储能 SOC、负荷乘数和 PV 辐照。训练为 LLM、LMH、MML、MHH、HHL、HLM；验证为 MLH、HML；测试为 LHL、HMH、MMM。A 的 L/M/H 初始 SOC 为 10.0012%、10.0032%、10.0100%，B 为 20%、35%、50%。负荷乘数为 0.73、0.75、0.77，PV 辐照为 0.50、0.72、1.00（相对额定）。6/2/3 是独立工况数，同一状态的派生查询不增加独立样本数。

每组在动作槽 24 和 27 对原生两端分别恢复初态，复核两个相同后续动作。每个状态只走六条爬坡后维持的策略，每条覆盖 13 个整秒，另用独立 DSS 实例复核该路径所有物理读回。基线从相同动作前缀恢复并执行零增量动作，PCC 增量为基线进口减候选进口。允许 3 s 达到，达到后另持 2、5 或 10 s。量化步长 0.1 kW，读回裕度 0.005 kW。每个查询保存可实证的最早到达拍及对应路径。无见证记为未核实。每状态保存逐相电压、储能读回和能量、PV 与储能端口 P/Q/S 以及拒绝原因；沿用既有变压器绕组校验，未独立认证线路热限。安全执行的见证违规与模型未获见证的过承诺分别统计。

输入为决策时可见的本地 SOC 和可用能量、实测设备与 PCC 出力、两个最小逐相电压裕度、上一功率指令和爬坡、当地负荷/辐照设定，以及本次查询的功率/时长。冻结训练种子 4471、原生采集种子 2781。训练工况拟合尺度，12 单元单隐藏层拟合相同状态与时长下的可交付功率，并在给定查询功率下区分 1/2/3 秒到达及无见证。160 次全批次 Adam 更新。查表基线在相同端口、时长和请求下，用相同输入选出两个不同训练工况中最近的状态，取较小的功率和两者均支持时较晚的到达时间。两者使用相同验证网格 0、0.5、1、2 kW 取安全降额，完全保留原始预测作为对照。测试结果分开按三个联合留出工况报告。

检验分组及来源指纹唯一、全部有界路径独立读回、长时见证的同达时短前缀、训练标签有效性。任一门失败即停。小样本的不确定性用验证绝对误差 90% 分位数及测试覆盖率作描述，不承诺统计覆盖。旧渐进接力只读取两个既有回合，逐点对齐窗口峰/谷附近的原生频率和两个输电侧传感器读回。

## 南洋原生结果

11 个原生回合均完成，共用时 1572.86 s（每组 132.19–177.76 s）。44 个决策状态生成 132 个状态/时长标签、660 行请求/时长查询。六条确定性策略共 264 条候选路径、3432 个仿真保持步；每条另从同初态完整重放验证。按命令日志开始至各组完成清单计，DSS 标签和见证累计约 208.7 s，与后续原生回合部分重叠。44 个初态逐一核对来自前一已完成的本地步。44 次误用未来动作槽和一次复制训练来源到测试组的负对照均被拒绝。

所有获准见证步均通过已建模的功率、能量、爬坡、相电压和相关设备额定检查。实测相电压总范围 0.956148–1.049344 pu，最低储能 SOC 10.000030%。候选目标被拒原因累计出现能量 524 次、爬坡 44 次、PV 可用量及端口短交付各 917 次；后两项记录的是同一组拒绝。一条轨迹的多次拒绝可重复计数。没有来源可靠的线路热额定，也没有让估计器在线派发设备。

小 MLP 使用训练种子 4471，249 个参数，全批次 Adam 共 160 次更新，参数改变量 L2 为 6.810874，初末损失 0.569418／0.172495，CPU 训练计时 0.329 s。独立评估进程读回的权重状态 SHA256 为 `fbe12ebc20dd6eaea803a90ef56af127181493fd70405de408fe3de2b9bb36f3`。验证选中 MLP 降额 2 kW，此时过承诺 3/24（12.5%），超过预设的 10% 选择目标；依冻结规则保留最低实测过承诺并报告缺口。查表在验证组零降额已满足该项。测试不参与选择。

|---|---:|---:|---:|

| 全样本平均正超额 / 最大超额 (kW) | 1.833 / 7.830 | 0.856 / 5.830 | 0.842 / 8.700 |

降额 MLP 的五次时长过报含两次无正时长见证却报 10 s、两次仅证实 2 s 却报 10 s，以及一次无正时长见证报 2 s。三组测试中 LHL、HMH、MMM 的 MLP 功率 MAE 分别为 2.731、5.515、1.347 kW，查表为 2.525、5.383、0.375 kW。两种方法的 HMH 过承诺均为零，功率误差主要是低估。验证集绝对误差 90% 分位数，降额 MLP 为 8.138 kW、查表为 8.700 kW；对应测试覆盖率 33/36、32/36。区间很宽，三个独立测试工况不足以评定不确定性的泛化能力。实际可达上限未知，表中超额以六条有限策略的安全见证为参照。较低持续过报和较小最大功率超额是本次 MLP 的权衡，整体结果不足以替代查表或部署。

## 复跑及证据

在南洋隔离的原生源码提交 `0163ee2ff5c3765b1fad8ed5cb17479153b3f231` 运行 `bash research/lfc_dual_pcc/collect_groups.sh`。指定 `LFC_STAGE0`、`LFC_PARENT_GATE`、`LFC34_REFERENCE`、全新 `LFC_GROUP_OUT`。成对方案及分组恢复脚本首次冻结于 `5dad7eb7b3704b7626fe85ca03fde24111b8f4f7`。在实际训练和评估头 `02a92fe3e008411b0074aa12e70fa86b5eec5534`，添加既有 `LFC_CASE_OUT`、`LFC_HANDOFF_OUT` 后运行：

```bash
bash research/lfc_dual_pcc/fit_grouped.sh
```

`sources/` 保存各组原始主配网记录；`labels/<组>/<槽>-<端>/` 保存独立初态与候选轨迹；`dataset/seal.json` 固定数据划分；`train/updates.json`、`train/estimator.pt` 保存更新和实际模型；`evaluation/evaluation.json`、`evaluation/predictions.json` 分别保存汇总和原始预测。绘图入口直接使用这些数据。同一模型的只读复核可在实际训练头单独执行：

```bash
"$HOME/miniconda3/envs/HARL/bin/python" -m research.lfc_dual_pcc.grouped_estimator evaluate --data "$LFC_GROUP_OUT/dataset" --checkpoint "$LFC_GROUP_OUT/train/estimator.pt" --out "$FRESH_EVALUATION_DIR"
```

[原有接力窗的独立诊断](handoff-span.md) 给出峰谷、两端实测、回传时序和因果边界。这批结果限单个主网阶跃、单次学习种子与本地电压源固定的两个 IEEE34。
