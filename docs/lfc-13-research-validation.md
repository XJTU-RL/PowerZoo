# 13Bus LFC：联合仿真的时钟与验证边界

## 两种时钟

- 默认 `env.aligned_clock=false`，继续使用论文移植路径。初始化和第一次动作都写入同一个 1 s 暂停目标；此前在 MATLAB R2025b 观察到实际暂停在 1.0333 s 和 1.0500 s，第一步传入了新的配电功率，但下一步才读到不同输电响应。这不是两个完整的一秒控制间隔。
- 显式 `env.aligned_clock=true` 为实验模式，不等同于论文口径；只接受布尔值，字符串不会启用。初始化目标为 1 s，此后第一个动作目标为 2 s，第 N 个动作目标为 N+1 s；StopTime 为 N+2 s，为最后一次暂停留出余量。调度检查不会重写 Simulink 模型。
- 在 Python 中设置 `LFCConfig(..., aligned_clock=True)` 可做非训练探测。诊断 `info["coupling_timing"]` 记录目标 `target_s`、实际暂停 `pause_s`、时钟通道 `out_t` 的最新值 `clock_sample_s` 和实际暂停间隔 `dt_s`。后一值在 reset 尚无上一暂停时为 None。两条实际时钟都须严格推进。暂停须在目标与其后 0.05 s 之间（允许三个 60 Hz 步长；实测延迟两个）；时钟记录不得比目标早超过 0.2 s（一个记录周期），也不能晚于实际暂停。未通过、观测错误或其他步进异常会使本回合失效；只能在 reset 成功后继续。
- `out_t` 只是独立的 Simulink 时钟记录，并非每个观测信号的时间戳。模型的频率输出和同步机输出是独立记录通道，配置采样间隔分别为 0.2 s 和 1 s。不能用 `clock_sample_s` 为这两条通道赋时间戳，也不要求数值每步都有变化。

## 南洋 13Bus 小步验证

Linux、MATLAB R2025b 与 DSS-Python 0.15.7，使用 13Bus 的 `IEEE13Nodeckt_duty.dss`，3 步控制上限，固定光伏动作 0.5、随机种子 17。在加固后的精确版本（`305281f8`）中复测了零储能动作，目标为 1、2、3、4 s，实际暂停为 1.0333、2.0333、3.0333、4.0333 s，独立 `out_t` 记录为 1、2、3、4 s。第三个动作按预期结束；StopTime 为 5 s，结束后 reset 可重新到 1.0333 s，时钟间隔恢复为 None。实际 GSP 频率在第一个动作后由 59.96500 Hz 变为 60.03119 Hz，三台同步机的有功和转速均为有限值并发生变化。

此前的原型（`8a498118`）用 0 和 +0.5 储能动作做配对探测；两组初态、暂停和独立时钟记录一致，末步按预期结束。加固版本未重跑 +0.5 对照。首个动作返回时，驱动 Simulink 的接口 P/Q 从零储能动作组的 −2.49164 MW / +7.92470 Mvar，变为 −15.96662 MW / −6.27231 Mvar；GSP 频率为 60.03119 与 60.08777 Hz。两组的三台同步机有功与转速也已有差异。该对照核对响应和时序，不是调频优劣测试。

## 验收边界

当前原型只处理动作/暂停时钟。连续动作后要检查终止步是否真正返回、重置是否清除上回合时钟，并用实际 P/Q、频率和三台机组响应验证联合仿真，而不只检查运行状态。研究模式的结果与论文默认模式分开报告，不据此推定储能能量守恒、接口双向反馈、训练收敛或论文曲线已验收。

## 离线储能账本与接口边界

`envs/lfc/diagnostics/storage_ledger.py` 以实际测量的储能交流端口有功（流入为正，放电为负）、实测间隔秒数和明确的充放电效率计算期望能量变化，并与代理储能报告的 kWh 对比。检查包括单步及累计残差、SOC 边界，以及固定功率因数下的无功一致性。旧版 Generator 代理的整数 kWh 舍入可能丢掉秒级小脉冲；基于功率因数设定的无功仍需以端口实测核对，不能用动作指令替代。

这份账本只有合成数据测试，尚未接入求解器、读取真实运行轨迹或使用 OpenDSS 原生 Storage；不会改变默认或实验时钟的运行行为。现有 Bus 8 接口已观察到 OpenDSS 的 P/Q 写入 Simulink 以及输电频率对该动作的响应（输电频率也作为控制观测返回），但这不等于双向电气耦合。尚须验证输电侧实测电压反馈确实改变 OpenDSS 电源边界并影响下一次配电潮流。
