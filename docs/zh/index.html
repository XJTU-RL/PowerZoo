系统架构

PowerZoo 采用分层架构设计，将训练编排、算法实现、神经网络模型与环境仿真清晰解耦。

训练层

On-policy 与 Off-policy 运行器，提供统一的缓冲区管理、日志记录和评估循环。

算法层

15种MARL算法，涵盖 HAPPO、MAPPO、MADDPG、QMIX 及双时间尺度VVC方法。

模型层

灵活的策略网络和价值函数网络，支持 MLP、RNN 和注意力机制架构。

环境层

4个电力系统环境，基于 OpenDSS 联合仿真，支持9个IEEE标准测试馈线。

交互探索算法继承体系、训练流水线以及运行器-算法映射关系。

各算法内部架构

各算法族的详细数据流图，展示网络组件、前向传播和训练机制。

仿真环境

四个多样化的电力系统环境，覆盖电压控制、新能源接入、电力市场和故障恢复。

🔌

PowerZoo VVC

电压无功控制环境：通过电容器投切、调压器分接头调节和储能调度，基于 OpenDSS 实时联合仿真实现配电网电压无功优化。

电容器 调压器 储能

测试系统：13节点、34节点、123节点、8500节点

SmartGrid

模块化智能电网环境：支持高渗透率光伏接入、课程学习策略及可配置的光伏扩展场景。

光伏控制 课程学习 模块化

测试系统：34节点光伏（保守型 / 优化型 / 激进型）

电力公司与消费者之间的领导者-跟随者博弈，包含分时电价、储能管理和 N-1 安全分析。

电力公司（领导者） 8个消费者 分时电价

快速开始

通过 conda 和 pip 快速搭建 PowerZoo 环境。

安装

# 克隆仓库
git clone https://github.com/XJTU-RL/PowerZoo.git
cd PowerZoo

# 创建 conda 环境
conda env create -f environment.yml
conda activate powerzoo

# 或通过 pip 安装
pip install -r requirements.txt

快速启动

# 在 IEEE 13节点 VVC 环境上训练 HAPPO 算法
python examples/multi_agent/scripts/train.py \
    --env powerzoo \
    --algo happo \
    --system 13Bus \
    --num_env_steps 100000 \
    --experiment_name my_first_run
