# IEEE123 接收侧开环标定 v1

使用 IEEE123 原生馈线、三机九节点及同一 Bus8 动态支路。每臂新开原生进程和 DSS 上下文，沿用原模型噪声、负荷、调速器、起始 SOC、原始分接稳定后固定的设置。原生存储指令固定为零，PCC 的实测小波动照常进入两通道，另在动态支路上单独叠加一个阶跃。正号为负荷进口增加。Q 保留为独立潮流试验。该标定验证接收侧，不衡量 DER 调频绩效。全程零阶保持，实际写入时刻以仿真暂停回读为准。1/60 s 为电气步，1 s 为通信步，两个电气步是写入时序护栏。Bus8 频率取同一 Timeseries 自带的原生 0.2 s 时间戳。

开放事件设计取四台储能既有合计 200 kW 指令上限的五分之一作为有功量级，不下发该功率到储能。无功独立采用 40 kvar；其正负不预设频率方向。计划同源零 A/B、P 正负、Q 正负六次独立运行。20 s 预热，计划 22–26 s 脉冲，32 s 结束。每次保存每帧实际暂停、设备实测、SOC、功率/能量检查、PCC、已读回的支路指令、Sensor7 末段均值及原生频率。设备约束结论限于实际采集的通道；线路热额定缺失。无 ACE 指标。

绝对工作点沿用 coupling_v1；相对零 A，PCC 两通道各允许 0.05 kW/kvar 漂移，Sensor7 激励通道各帧误差 ≤5 kW/kvar，静置/非激励通道 ≤1 kW/kvar。零 A/B 频率最大差限 50 µHz。可辨门槛为 max(10 µHz, 3 × 零重复最大差)，预脉冲不得越界。有功预期增负荷降频、减负荷升频，检查连续两原生样点越过同一方向门槛，报告第一点与实际写入之间的延迟上界。无功只报绝对可见变化。恢复要求撤回后连续 1 s 进入噪声带，仅适用于已检测到的响应。所有时限为本观察窗；未检出或未恢复分别报告。时钟、同源性、绝对工作点、通道隔离或噪声门槛失败均保留已有记录并停止。可辨性失败不触发增大扰动或训练。

运行环境为南洋现有 HARL、MATLAB R2025b 和 Xvfb。每臂约 1.5–3 分钟（按已有探针估计），六臂最多 25 分钟；报告必须使用新的私有路径。下列命令从本功能工作树执行。

```sh
export PATH="$HOME/matlab_2025b/bin:$PATH" OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1
out=$(mktemp -d "$HOME/exps/lfc123-open-v1.XXXXXX") || exit
timeout --kill-after=15s 1500s xvfb-run -a "$HOME/miniconda3/envs/HARL/bin/python" -u -m scripts.check_lfc_123_transfer --report "$out/observed.jsonl"
```

## 八秒事件的闭环验收

开放设计事件 `+40 kW / 8 s`，单独运行无控制、切断 PCC 回传、闭环三臂。控制器等分到四台原生储能，采用同一冻结参考、100000 kW/Hz 增益、0.1 mHz 死区、0.4 阻尼和 30 kW/s 总变率。每帧整组向量在独立 DSS 上下文验算，验证真实终端、SOC/能量、容量、设备电压/电流和预测/实测一致后才向传输侧写入；任一不合格即停。此工程控制器采用等分与整组试算，单独命名，未启用过去阻尼 v1 的设计/持留事件。回传切断保留同一控制器、储能动作与 DSS 解，只隔离 PCC 对支路命令的贡献。验收要求实际受扰时段至少 6 个连续通信帧中，配网支援经物理传感器实测超过 1 kW，加上与断链臂可辨的后续频率差。固定下垂、学习方法和论文 13Bus 均保留原始边界。本模型仅验证频率—资源—PCC 功率的双向控制链；配网电压源为既定边界。

```sh
export PATH="$HOME/matlab_2025b/bin:$PATH" OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1
```
