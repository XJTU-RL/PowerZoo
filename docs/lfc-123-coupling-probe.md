# IEEE 123 → IEEE9 Bus 8 单向功率传递探针

本实验属于优化 LFC 场景，不是论文复现，不改论文模型、不注册训练环境。Bus 8 的
动态负荷通过 `load1p` / `load1q` 接受等值功率，是与同母线固定
`Load C 100 MW 35 MVAr` 并联的另一元件。不要再次向动态支路加入
100 MW / 35 MVAr。脚本不改变固定负荷、其他区域负荷、断路器或
Simulink 拓扑。

`scenarios/lfc/ieee123-native/coupling_v1.json` 固定模型摘要与待测始点：
论文 13 节点流程 seed 17、rank 0 在 1.033333 s 的复位接口命令为
7,851.739821876 kW / 12,942.530488712 kvar，当时 GSP 频率约
59.965001 Hz。这是此前观测的初始条件，不是稳态证明。123 配电侧
的原生静态始点约 3,615.265 kW / 1,311.528 kvar，算术背景是二者
相减；不对配电设备或潮流结果放大。实际命令采用这个始点叠加实时
测得的 123 馈线 P/Q 增量，kW/kvar 到 W/var 转换一次。

## 按以下顺序执行

需要已有 MATLAB R2025b、匹配 Python Engine、有有效许可证的
Simulink/Simscape Electrical，以及已有 DSS-Python。无桌面时使用
Xvfb；不得把缺少许可证、引擎或测量通道当作通过。模型与所需辅助脚本
复制到单独的临时目录，在带超时的验证进程运行，逐个核对原始模型和四个随模型提供的白名单 MATLAB 脚本的 SHA-256；不复制其他脚本。

```sh
python -m unittest tests.test_lfc_123_native tests.test_lfc_123_coupling_probe
xvfb-run -a timeout --kill-after=15s 240s python -m scripts.check_lfc_123_coupling
# 独立预热曾通过后，可执行一个含预热的短传递探针：
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  xvfb-run -a timeout --kill-after=15s 480s python -m scripts.check_lfc_123_coupling --coupled
```

1. 默认只跑 20 s 的恒定动态负荷，取最后 3 s 的实际功率传感器
   Pm、Qm 与 GSP 频率。命令回读不能替代功率传感器。若 Simscape
   日志缺少 Pm、Qm 或时序覆盖，停止并报告缺项；不填零、不放宽门槛。
2. 显式请求 `--coupled` 时只启动一次 MATLAB 仿真：同一次仿真先预热，再做短传递。
   每次 Simulink 停在新的通信边界时由原生 IEEE 123 求解一帧，随后
   将实测净输入增量送给 Bus 8 动态负荷。固定基步长是 1/60 s，
   通信间隔 1 s，实际暂停允许模型断言最多迟两个基步。
   结束读到物理日志后，必须复核同次预热的真实 P/Q 及频率，
   再验收各帧传感器；预热不合格则不能报告传递通过。
3. 四帧为无动作、每台放电 50 kW、每台充电 50 kW、无动作。各台
   实测端口 P 与命令相差不超过 0.05 kW，且 |Q| 不超过 0.05 kvar，
   并须有完整端口记录。两段脉冲的馈线入口 P 与两个无动作帧相比
   必须分别至少降低和增加 150 kW，Bus 8 的等宽传感器窗均值
   必须分别至少降低和增加 100 kW。物理 Bus 8 P/Q 仍须满足命令
   跟踪绝对误差门槛，但不把 Q 的偏差限当成识别到 Q 脉冲的证据。
4. 这些是单向传递、非零响应和极性的验收。短探针不根据频率闭环，
   不验证控制收益，也没有独立全程无动作及等量 P/Q 回放对照。
   配电侧仍是刚性电源，输出报告不得描述为双向耦合、训练通过或论文复现。
   时序负荷和 OEDI 数据不是本实验的一部分。

R2025b 已独立验收恒定始点：实体传感器最后 3 s 的 P/Q 平均值
为 7,875.699 kW / 12,928.046 kvar，频率平均值 59.968050 Hz；
频率原生记录 0.2 s 采样，与电气日志分别检查。第一次短传递退出码为 1：首个无动作窗口末端的实体有功样本为
7,668.207 kW，与命令最大偏差 183.532 kW，未通过 100 kW 门槛。
该单点与下一帧放电方向相符，但这不能证明因果归属。新版仅取实际
暂停之间的开区间，暂停时刻 ±0.1 微秒内的样本单列，不归给任一帧。
物理 P/Q 窗口必须覆盖到末端前一个 1/60 s 采样步，并保持连续；
频率仍用自己的 0.2 s 采样。退出失败时也输出四帧已取得的窗口、
暂停边界和被排除的边界点，不改物理门槛。

## 同步边界复核结果

在 MATLAB R2025b、DSS-Python 0.15.7 下，按上述命令对修订版
`b0bcbe0` 单次验证，119 s 退出码为 0，返回
`sequential_one_way_transport_passed`。实际暂停从 20.033333 s
开始，到 24.033333 s 结束，相邻暂停间隔均为 1 s。未改跟踪门槛。
首次误归给无动作帧的 7,668.207 kW 样本在复核中原值重现：它位于
21.033333 s 暂停处，与紧随其后的放电窗实测 7,668.064 kW 一致，
而暂停前无动作窗实测 7,875.699 kW。暂停时刻本身不归给任一帧。

| 帧 | 四台储能各自实测有功（kW） | 123 馈线实测 P / Q（kW / kvar） | Bus 8 窗口实测均值 P / Q（kW / kvar） |
| --- | ---: | ---: | ---: |
| 无动作 | 0 | 3615.265 / 1311.528 | 7875.699 / 12928.046 |
| 放电 | +50 | 3408.614 / 1286.705 | 7668.064 / 12904.154 |
| 充电 | −50 | 3824.211 / 1340.673 | 8085.704 / 12956.183 |
| 无动作 | 0 | 3615.265 / 1311.528 | 7875.679 / 12928.062 |

相对于两段无动作，Bus 8 放电帧至少降低 207.616 kW，充电帧
至少升高 210.005 kW；各帧窗口最大的绝对 P/Q 跟踪误差为
25.090 kW / 15.544 kvar，低于 100 kW / 100 kvar。各台储能
实测 |Q| 均小于 0.05 kvar。Bus 8 频率只作为诊断记录，本次
不验证调频效果、双向耦合、训练或跨场景对比，不发布原始日志。
