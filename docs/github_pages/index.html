Architecture

PowerZoo employs a layered architecture that cleanly separates training orchestration, algorithm implementation, neural network models, and environment simulation.

Training Layer

On-policy and off-policy runners with shared buffer management, logging, and evaluation loops.

Algorithm Layer

15 MARL algorithms including HAPPO, MAPPO, MADDPG, QMIX, and two-timescale VVC methods.

Model Layer

Flexible policy and value function networks with MLP, RNN, and attention-based architectures.

Environment Layer

4 power system environments with OpenDSS co-simulation, supporting 9 IEEE test feeders.

Environments

Four diverse power system environments covering voltage control, renewable integration, electricity markets, and fault recovery.

🔌

PowerZoo VVC

Getting Started

Set up PowerZoo in minutes with conda and pip.

Installation

# Clone the repository
git clone https://github.com/XJTU-RL/PowerZoo.git
cd PowerZoo

# Create conda environment
conda env create -f environment.yml
conda activate powerzoo

# Or install via pip
pip install -r requirements.txt

Quick Start

# Train HAPPO on IEEE 13-Bus VVC environment
python examples/multi_agent/scripts/train.py \
    --env powerzoo \
    --algo happo \
    --system 13Bus \
    --num_env_steps 100000 \
    --experiment_name my_first_run
