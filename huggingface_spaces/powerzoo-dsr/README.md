# PowerZoo DSR: Distribution Service Restoration Environment

Interactive demo for the DSR (Distribution Service Restoration) environment in PowerZoo.

Features heterogeneous agents: 1 Switch agent, N PV agents, N Load agents,
with discrete action spaces and action masks for fault recovery scenarios.

**Paper**: IEEE Transactions on Smart Grid, 2025

**GitHub**: [PowerZoo Repository](https://github.com/XJTU-RL/PowerZoo)
