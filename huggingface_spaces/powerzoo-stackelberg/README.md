# PowerZoo Stackelberg: Market Game Environment

Interactive demo for the Stackelberg game environment in PowerZoo.

Features heterogeneous agents: 1 Utility Company (UC) leader with 5D continuous actions
(price/DR/ESS) and N consumer followers with 3D actions (load/DER management).

**Paper**: IEEE Transactions on Smart Grid, 2025

**GitHub**: [PowerZoo Repository](https://github.com/XJTU-RL/PowerZoo)
