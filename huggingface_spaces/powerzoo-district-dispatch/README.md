# PowerZoo District Dispatch: Multi-Zone Coordination Environment

Interactive demo for the District Dispatch environment in PowerZoo.

Features 3-zone coordination on IEEE 34-Bus system with zone-level dispatch agents
managing inter-zone power flow and local device control.

**Paper**: IEEE Transactions on Smart Grid, 2025

**GitHub**: [PowerZoo Repository](https://github.com/XJTU-RL/PowerZoo)
