# 温度数据扩展指南

## 问题描述

原始的24小时温度数据只有24个点（每小时一个点），但OpenDSS的duty模式仿真需要8640个点（10秒间隔，24小时）。本指南提供了三种将24点扩展为8640点的方案。

## 原始温度数据

```dss
New Tshape.MyTemp npts=24 interval=1 temp=[25, 25, 25, 25, 25, 25, 25, 25, 35, 40, 45, 50, 60, 60, 55, 40, 35, 30, 25, 25, 25, 25, 25, 25]
```

这个数据表示：
- 夜间（0-7时）：25°C
- 白天升温（8-12时）：35°C → 60°C
- 下午降温（13-23时）：60°C → 25°C

## 三种扩展方案

### 方案1：简单重复

**特点：**
- 每小时的温度值重复360次
- 实现最简单
- 温度变化呈阶梯状

**适用场景：**
- 快速测试
- 对温度精度要求不高的仿真

**DSS配置：**
```dss
New Tshape.MyTemp npts=8640 interval=10s temp=(file=./temperature_method1.csv)
```

### 方案2：线性插值

**特点：**
- 相邻小时之间线性过渡
- 温度变化平滑
- 符合物理直觉

**适用场景：**
- 需要平滑温度变化的仿真
- 理想化的温度模型

**DSS配置：**
```dss
New Tshape.MyTemp npts=8640 interval=10s temp=(file=./temperature_method2.csv)
```

### 方案3：真实波动（推荐）

**特点：**
- 基于线性插值
- 添加周期性波动（±1°C，15分钟周期）
- 添加随机噪声（±0.5°C）
- 小时内温度过渡
- 最接近真实温度变化

**适用场景：**
- 高精度光伏仿真
- 研究温度波动对系统的影响
- 真实场景模拟

**DSS配置：**
```dss
New Tshape.MyTemp npts=8640 interval=10s temp=(file=./temperature_method3.csv)
```

## 使用步骤

### 1. 生成温度数据

```bash
cd /path/to/34BUS_with_PV
python generate_temperature_data.py
```

这将生成三个CSV文件：
- `temperature_method1.csv` - 简单重复方案
- `temperature_method2.csv` - 线性插值方案
- `temperature_method3.csv` - 真实波动方案（推荐）

### 2. 修改DSS文件

将原来的温度定义：
```dss
New Tshape.MyTemp npts=24 interval=1 temp=[25, 25, 25, ...]
```

替换为（推荐使用方案3）：
```dss
New Tshape.MyTemp npts=8640 interval=10s temp=(file=./temperature_method3.csv)
```

### 3. 确保仿真设置匹配

确保duty模式设置为8640个时间步：
```dss
Set mode=duty number=8640 hour=0 stepsize=10 sec=0
```

## 温度波动模型说明（方案3）

### 周期性波动
- **周期**：15分钟
- **幅度**：±1°C
- **公式**：`1.0 * sin(2π * t / 900)`
- **目的**：模拟短期温度自然波动

### 随机噪声
- **分布**：正态分布
- **标准差**：0.3°C
- **范围**：约±0.5°C
- **目的**：模拟测量误差和微环境影响

### 小时内过渡
- **机制**：在小时后半段向下一小时温度过渡
- **强度**：30%的温度差值
- **目的**：避免小时边界的突变

## 推荐配置

对于大多数光伏仿真应用，推荐使用**方案3（真实波动）**：

```dss
! 推荐的温度配置
New Tshape.MyTemp npts=8640 interval=10s temp=(file=./temperature_method3.csv)

! 光伏系统配置
New PVSystem.PV1 Bus1=890 phases=3 kV=4.16 Pmpp=250 irradiance=MyIrrad temperature=MyTemp

! 仿真设置
Set mode=duty number=8640 hour=0 stepsize=10 sec=0
```

这种配置提供了：
- ✅ 与仿真时间步完全匹配的温度数据
- ✅ 真实的温度波动特性
- ✅ 更准确的光伏发电模拟
- ✅ 适合研究温度对系统性能的影响

## 注意事项

1. **文件路径**：确保CSV文件路径正确
2. **数据格式**：CSV文件每行一个温度值，保留2位小数
3. **仿真时间**：确保温度数据点数与仿真时间步数匹配
4. **温度范围**：生成的温度数据已限制在0-80°C范围内
5. **随机性**：方案3使用固定随机种子，确保结果可重现

## 验证方法

运行仿真后，可以通过以下方式验证温度数据是否正确应用：

```dss
! 导出温度数据
Export Tshape MyTemp

! 查看光伏系统温度
Show PVSystem.PV1 Temperature
```
