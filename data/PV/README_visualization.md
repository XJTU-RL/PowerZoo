# PV数据综合可视化分析系统

## 系统概述

本系统是一个专为光伏(PV)数据设计的综合可视化分析工具，能够对太阳能发电相关的气象数据进行多维度、多层面的深度分析和可视化展示。

## 主要功能

### 🌞 太阳辐射分析
- **全球水平辐射(GHI)时间序列**: 展示太阳辐射的时间变化规律
- **直射辐射(DNI)分析**: 分析直射太阳辐射的变化模式
- **散射辐射(DHI)统计**: 研究散射辐射的分布特征
- **日变化模式**: 分析太阳辐射的日内变化规律
- **辐射分布直方图**: 统计不同辐射强度的频率分布

### 🌡️ 温度分析
- **多点温度对比**: 对比不同测量点的温度数据
- **温度日变化模式**: 分析温度的日内变化规律
- **温度与辐射相关性**: 研究温度与太阳辐射的关系
- **湿球温度、干球温度、露点温度分析**

### 🌤️ 天气条件分析
- **风速风向分析**: 多高度风速对比和风向分布
- **云量统计**: 云覆盖率的分布特征
- **湿度变化**: 相对湿度的时间序列和分布
- **气压分析**: 大气压力的变化趋势

### 📊 相关性分析
- **变量相关矩阵**: 关键气象参数间的相关性热力图
- **多变量关系**: 深入分析各气象要素的相互影响

### 📈 统计摘要
- **描述性统计**: 均值、标准差、最值等统计指标
- **数据分布**: 箱线图展示数据的分布特征
- **数据质量评估**: 异常值检测和数据完整性分析

## 使用方法

### 1. 单文件分析

```bash
# 分析单个数据文件
python comprehensive_data_visualizer.py txt/202501.txt -o output_directory
```

**参数说明:**
- `txt/202501.txt`: 输入数据文件路径
- `-o output_directory`: 输出目录（可选，默认为 `visualization_results`）

### 2. 批量分析

```bash
# 批量处理整个目录下的所有数据文件
python batch_visualizer.py txt/ -o batch_output_directory
```

**参数说明:**
- `txt/`: 输入数据目录路径
- `-o batch_output_directory`: 输出基础目录（可选，默认为 `batch_visualization_results`）

### 3. 查看结果

分析完成后，可以通过以下方式查看结果：

1. **HTML索引页面**: 打开 `comprehensive_visualization_results/index.html`
2. **详细报告**: 查看各子目录中的 `README.md` 文件
3. **图表文件**: 直接查看各分类目录中的PNG图表文件
4. **统计数据**: 查看 `statistical_summary/data_statistics.csv` 文件

## 输出说明

### 图表类型

每个数据文件的分析会生成以下类型的图表：

1. **太阳辐射分析** (solar_radiation/)
   - `radiation_timeseries.png`: 辐射时间序列图
   - `daily_radiation_patterns.png`: 日变化模式图
   - `radiation_distributions.png`: 辐射分布直方图

2. **温度分析** (temperature_analysis/)
   - `temperature_analysis.png`: 温度时间序列和日变化
   - `radiation_temperature_correlation.png`: 辐射-温度相关性散点图

3. **天气条件** (weather_conditions/)
   - `weather_analysis.png`: 风速、风向、云量、湿度分析

4. **相关性分析** (correlation_analysis/)
   - `correlation_heatmap.png`: 变量相关性热力图

5. **统计摘要** (statistical_summary/)
   - `box_plots.png`: 数据分布箱线图
   - `data_statistics.csv`: 详细统计数据

### 数据质量

- **数据清洗**: 自动过滤异常值和无效数据
- **缺失值处理**: 识别和标记数据缺失情况
- **单位统一**: 确保所有数据使用正确的物理单位
- **时间戳校验**: 验证时间序列的连续性和准确性

## 数据格式要求

### 输入数据格式
- **文件格式**: CSV或TXT文件，逗号分隔
- **时间列**: 前5列必须为年、月、日、时、分
- **数据列**: 第6列开始为各种气象参数
- **字段定义**: 参考 `filed_definition.md` 文件

### 示例数据格式
