# PV数据与OpenDSS集成指南

## 概述

本指南详细说明如何将PV数据目录中生成的日数据提供给OpenDSS的`ieee34Mod1_duty.dss`文件使用。通过自动化集成工具，可以轻松地将任意日期的PV数据转换为OpenDSS兼容格式并进行电力系统仿真。

## 问题分析

### 当前状况
- **PV数据格式**: 1分钟间隔，1440个数据点/天
- **OpenDSS配置**: 10秒间隔，360个数据点
- **数据不匹配**: 时间间隔和数据点数不一致

### 解决方案
采用数据适配方法，将OpenDSS配置修改为1分钟间隔以匹配PV数据，保持数据完整性。

## 集成工具使用

### 1. 工具概述

`pv_opendss_integrator.py` 是一个自动化集成工具，提供以下功能：
- PV数据格式转换
- OpenDSS配置文件自动生成
- 批量处理支持
- 数据验证和路径管理

### 2. 基本使用方法

#### 查看可用日期
```bash
python pv_opendss_integrator.py --list-dates
```

#### 集成单个日期的数据
```bash
# 集成2025年1月1日的数据
python pv_opendss_integrator.py --date 2025-01-01

# 指定输出文件
python pv_opendss_integrator.py --date 2025-01-01 --output custom_config.dss
```

#### 批量集成
```bash
# 批量处理所有可用数据
python pv_opendss_integrator.py --batch

# 批量处理指定日期范围
python pv_opendss_integrator.py --batch --start-date 2025-01-01 --end-date 2025-01-31

# 限制处理文件数量
python pv_opendss_integrator.py --batch --max-files 10
```

#### 交互模式
```bash
# 直接运行，进入交互选择模式
python pv_opendss_integrator.py
```

## 集成过程详解

### 1. 数据转换流程

#### 输入数据格式
- **完整数据**: `20250101_complete_data.csv`
  ```csv
  datetime,hour,irradiance,irradiance_mult,temperature
  2025-01-01 00:01:00,0.016666666666666666,0.0,0.0,-6.02
  ```

- **辐照度时序**: `20250101_irradiance_timeseries.csv`
  ```csv
  hour,Mult
  0.016666666666666666,0.0
  0.03333333333333333,0.0
  ```

- **温度时序**: `20250101_temperature_timeseries.csv`
  ```csv
  Hour,Temp
  0.016666666666666666,-6.02
  0.03333333333333333,-6.009
  ```

#### 输出DSS配置
```dss
! OpenDSS Configuration for PV Data - 2025-01-01
! Generated by PV-OpenDSS Integrator
! Data points: 1440, Interval: 1 minute

! 设置仿真模式
Set Mode=duty
Set stepsize=60s
Set number=1440

! 定义负载形状
New LoadShape.MyIrrad npts=1440 interval=1 mult=(file=loadshape/pv_data/20250101_irradiance.csv)
New TShape.MyTemp npts=1440 interval=1 temp=(file=sim_temperature/20250101_temperature.csv)

! 定义PV系统
New PVSystem.PV_20250101 phases=3 bus1=trafo_pv kV=0.48 kVA=200 irrad=0.5 Pmpp=180 temperature=25 PF=1 %cutin=0.1 %cutout=0.1 effcurve=Myeff P-TCurve=MyPvsT Duty=MyIrrad TDuty=MyTemp
```

### 2. 文件组织结构

集成后的目录结构：
```
34BUS/
├── ieee34Mod1_duty_20250101.dss    # 生成的配置文件
├── loadshape/
│   └── pv_data/
│       └── 20250101_irradiance.csv  # 辐照度数据
└── sim_temperature/
    └── 20250101_temperature.csv      # 温度数据
```

### 3. 关键配置参数

#### 仿真参数调整
- **时间步长**: 从10秒改为60秒 (`Set stepsize=60s`)
- **仿真点数**: 从360改为1440 (`Set number=1440`)
- **数据间隔**: 1分钟间隔 (`interval=1`)

#### PV系统参数
- **额定功率**: 200 kVA
- **最大功率点**: 180 kW
- **功率因数**: 1.0 (纯有功)
- **切入/切出阈值**: 0.1%

## 高级功能

### 1. 自定义PV系统参数

可以修改生成的DSS文件中的PV系统参数：
```dss
! 修改PV系统容量
New PVSystem.PV_20250101 kVA=500 Pmpp=450

! 修改连接节点
New PVSystem.PV_20250101 bus1=node_123

! 修改功率因数
New PVSystem.PV_20250101 PF=0.95
```

### 2. 多PV系统配置

可以在同一个配置文件中定义多个PV系统：
```dss
! PV系统1
New PVSystem.PV1 bus1=node_1 kVA=200 Duty=MyIrrad TDuty=MyTemp

! PV系统2
New PVSystem.PV2 bus1=node_2 kVA=150 Duty=MyIrrad TDuty=MyTemp
```

- 云层遮挡效应分析
- 系统稳定性评估

### 1. 数据完整性检查

- 辐照度值范围: 0-1200 W/m²
- 温度值范围: -40°C 到 60°C
- 夜间辐照度应为0

### 3. 仿真结果验证
- PV输出功率合理性
- 电压水平在允许范围内
- 功率平衡检查

## 故障排除

### 常见问题及解决方案

1. **文件路径错误**
   - 检查PV数据目录是否存在
   - 确认OpenDSS项目目录路径正确

2. **数据格式不匹配**
   - 验证CSV文件格式
   - 检查列名是否正确

3. **OpenDSS编译错误**
   - 检查DSS语法
   - 确认文件路径相对关系

4. **仿真收敛问题**
   - 调整仿真参数
   - 检查系统配置合理性
