# LFC 研究场景

LFC 有两条独立的场景线。两条线可以复用三机九节点输电模型，但必须分别记录馈线版本、时钟、设备、运行点和扰动，不合并结果。

| 场景线 | 用途 | 配电变体 |
| --- | --- | --- |
| [论文原版](paper/README.md) | 复现原论文的模型和行为，记录已知限制 | 13、34 |
| [优化版](optimized/README.md) | 验证修正后的接口、设备、物理约束和控制方法 | 13 时钟与储能、34 校准、123 原生储能；OEDI 123 为扩展候选 |

这是场景索引，不是运行时注册表。原有模型和配置路径保持兼容。优化版不能覆盖论文原版，也不能以目录存在代替验收。
