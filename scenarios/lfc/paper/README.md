# LFC 论文原版

保留论文使用的三机九节点 Simulink 模型、配套 OpenDSS 电路、设备代理及启动时序。文档说明原样行为，不用修正后的数据或曲线替代原版。

- [IEEE 13 原版](../ieee13-paper/README.md)：真实联仿与三步动作对照已通过；首步不是完整的一秒，训练与论文曲线未验收。
- [IEEE 34 原版](../ieee34-paper/README.md)：原始运行点已做诊断，初始储能 SOC、相位连接和预备工况主变负载存在问题，未通过物理验收、未做 MATLAB 联仿。后续校准结果单列为优化版。
- IEEE 123 和 OEDI 123 都不是论文原始 LFC 变体。
